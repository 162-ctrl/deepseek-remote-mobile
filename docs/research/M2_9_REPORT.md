# M2.9 报告：Kimi 风格重构

- 日期：2026-11-09
- 版本：`0.2.1+12` / `versionName 0.2.1-m2.9`
- APK：`dist/DeepSeek-Remote-AI-v0.2.1-m2.9.apk`（68,848,232 字节）

## 目标

用户发来两张 Kimi 真机截图（首页 + 抽屉），要求做成同样的观感。只改视觉与导航结构，不改连接、对话、审批、文件读写链路。

## 做法

### 设计令牌（`app/lib/theme/app_theme.dart`）

| 令牌 | 浅色 | 深色 |
|---|---|---|
| bg / card | `#FFFFFF` | `#0D0E12` / `#16181E` |
| line / lineSoft | `#ECEDF2` / `#F4F5F8` | `#23262E` / `#1B1E25` |
| text / text2 / text3 | `#111318` / `#5F636B` / `#9CA1AA` | `#F1F3F7` / `#A6AAB3` / `#6D727C` |
| accent / accentSoft | `#4C5CFF` / `#EEF0FF` | `#8A93FF` / `#1D2034` |
| 用户气泡 | `#EFF1FF` 底 + `#141726` 字 | `#262B47` / `#EEF0FF` |

圆角：card 18、sheetTop 28、bubble 20、bubbleTail 6、code 14、input 24、button 24、pill 999。
阴影：卡片单层 `0x08000000`、blur 14、offset (0,4)。

### 首页（`assistant_screen.dart`）

- 删除 AppBar 与底部导航。
- 顶栏：圆形菜单（40）· 中间设备胶囊（状态点 + 短设备名 + 展开箭头）· 右侧分享/历史圆钮。
- 未连接：品牌标记 58 +「还没有连接电脑」+ 说明 + 胶囊按钮。
- 已连接且无消息：品牌标记 +「嗨，今天要和 DeepSeek\n一起做点什么」（24 / w600 / 行高 1.5）+「已连接 · 设备」胶囊。
- 输入条上方快捷胶囊：全部项目 / 总结这次改动 / 跑通构建和测试。
- 输入条：白胶囊（描边 + 轻阴影），左「+」（全部项目 / 任务中心 / 连接设置），右发送钮；下方「内容由 AI 生成」。
- body 包 `SafeArea(bottom: false)`。

### 抽屉（`root_shell.dart`）

- 宽度 `min(86%, 400)`，右上下圆角 26，`elevation 0`。
- 头部：品牌标记 42 + 设备名 + 连接状态 + 「+」（回到对话）。
- 五个入口，选中为浅紫底 + 强调色。
- 「历史会话」列表（最多 12 条）+ 底部版本号。
- 四个子页统一 `KimiAppBar`（圆形菜单 + 26px 标题），任何页都能打开抽屉。

### 品牌标记（`widgets/app_mark.dart`）

蓝色渐变圆（`#7F9DFF → #3A59FF`）+ 两只白色竖椭圆眼睛，带 26 blur 柔光；用于首页、抽屉、空态。

### 四个二级页（任务 / 电脑 / 项目 / 我的）

- 统一改用 `KimiAppBar`：白底、无阴影、无分割线，toolbar 64，标题 26/w700/-0.4，左侧 40px 圆形菜单（白底 + 1px 描边），右侧操作按钮沿用图标。
- 列表顶部留白 10px；卡片仍是 `Panel`（白底 + 1px 线 + 18 圆角 + 4% 阴影）。
- `EmptyState` 重做：64px 浅灰圆底图标、18px 标题、13px 说明、胶囊按钮。
- 插件直连没有任务 REST 接口：`LiveStore._tasksRestUnavailable` 在首个 404 后静默，任务/详情由 WSS 推送维护。

## 已知限制

- 二级页是「顶栏 + 卡片」的 Kimi 化，不是逐像素复刻；Kimi 的列表分组、搜索、设置二级页未照搬。
- 未接 Kimi 的语音输入、新建项目、插件市场、订阅等业务功能。
- 深色模式沿用同一套令牌，未逐页校准对比度。
